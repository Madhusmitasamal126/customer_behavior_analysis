# Customer Shopping Behavior Data Analysis Project

## Overview

This project demonstrates an end-to-end **Data Analysis workflow** using Python, SQL, and Power BI. It includes data loading, exploratory data analysis (EDA), data cleaning, SQL business queries, interactive dashboard development, and a final presentation created with Gamma.

---

## Dataset

**Dataset:** Customer Shopping Behavior

The dataset contains customer purchase records, including:

* Customer ID
* Age & Gender
* Category & Product
* Purchase Amount
* Review Rating
* Shipping Type
* Discount Applied
* Subscription Status
* Previous Purchases

## Project Workflow

### 1. Data Loading

* Imported the CSV dataset using Pandas
* Inspected data types and missing values
* Created a structured DataFrame for analysis

### 2. Exploratory Data Analysis (EDA)

Performed analysis on:

* Customer demographics
* Purchase behavior
* Revenue trends
* Product categories
* Review ratings
* Shipping methods
* Subscription patterns

### 3. Data Cleaning

* Removed duplicates
* Handled missing values
* Corrected data types
* Standardized categorical values
* Prepared clean data for SQL and Power BI

### 4. SQL Analysis

Created business queries to answer questions such as:

* Revenue by gender
* Average customer spending
* Top-rated products
* Discount impact
* Subscription revenue
* Customer segmentation
* Category performance

### 5. Power BI Dashboard

Built an interactive dashboard featuring:

* KPI Cards (Revenue, Customers, Average Purchase)
* Category-wise Sales
* Gender Analysis
* Shipping Analysis
* Top Products
* Filters & Slicers for dynamic reporting

### 6. Report & Presentation

* Generated a professional analysis report
* Created a presentation using **Gamma**
* Summarized business insights with visual storytelling

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install pandas matplotlib jupyter
```

3. Open the Jupyter notebook:

```bash
jupyter notebook pandas_file.ipynb
```

4. Run all notebook cells to perform EDA and data cleaning.
5. Execute the SQL queries in your SQL database.
6. Open the `.pbix` file in **Power BI Desktop** to explore the dashboard.
